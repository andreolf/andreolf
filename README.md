## 🚀 Current projects

- 🦞 **[Clawloan](https://clawloan.com)** — the credit layer for AI agents, built for the [OpenClaw](https://openclaw.ai) ecosystem. Programmatic micro-loans: an agent borrows, completes its task, repays — no UI, no human approval, all on-chain.
- 📡 **[Solbeat](https://www.solbeat.xyz)** — the heartbeat terminal for the Solana network. Zero API keys, Python stdlib only, $0/month to run: it collects from 16 public sources, detects anomalies, computes REV, maps 1,200 validators, and refreshes itself forever on GitHub Actions.
- 🤖 **[walletpilot](https://github.com/andreolf/walletpilot)** — SDK for AI agents to execute on-chain transactions with user-granted permissions (MetaMask ERC-7715 delegations).
